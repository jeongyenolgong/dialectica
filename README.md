# 디알렉티카

기아 OU 워크숍 게임의 화면입니다. 참가자는 폰, 진행자는 노트북 한 대, 큰 스크린 하나로 합니다. 전부 개인전입니다.

| 누가 | 파일 | 어디서 |
|---|---|---|
| 참가자 | `p1-identity.html` → `p1b-pick.html` → `p2-status.html` → `p3-wait.html` · `p4p5-collect.html` | 폰 — **참가자 QR** |
| 참가자(재접속) | `reconnect.html` | 폰 — **재접속 QR**(참가자 QR과 따로) |
| 진행자 | `host.html` | 노트북 |
| 스크린 | `screen-01-entry.html` · `screen-02-collect.html` · `screen-review.html` · `screen-pair.html` · `screen-05-result.html` | 진행자 화면 오른쪽 위 「스크린」으로 열고, 단계에 따라 저절로 넘어갑니다 |

## 흐름

```
입장 → 수집 → 리뷰 → 짝 → 결과 → 종료   (진행자가 넘깁니다. 시간 제한 없음)
```

- **입장** — QR → 이름 → 고르기 다섯 판(판마다 여섯 단어 중 하나, 캐릭터마다 둘씩) → 내 상태(출발 비율) → 대기.
- **수집** — 포스터에서 읽은 단어 입력 → 그 단어의 Opposite 입력 → 거리 구에서 내 답의 자리 + 「+ 캐릭터 이름」 → 확인 → 다음 단어.
- **리뷰**(스크린, 폰은 대기) — 많이 고른 5개 목록 → 포스터 단어 30개를 하나씩: 구 위에 답끼리 가장 먼 두 사람, 옆에 나머지 전원의 이름·답.
- **짝**(스크린, 폰은 대기) — 답이 가장 먼 두 사람끼리(홀수면 한 팀은 셋), 한 쌍씩.
- **결과**(스크린, 폰은 대기) — 방 전체 캐릭터 비율의 시작 → 현재.

규칙과 셈의 자세한 내용·근거는 인계 문서 `HANDOFF.md`에 있습니다.

## 짧게

- 단어를 치면 폰이 30개와 견줘 찾습니다 — 띄어쓰기 무시, 자모 하나 차이는 통과.
- 게이지와 결과는 같은 셈입니다 — 캐릭터별 단어 개수(고른 5개 + 모은 단어)의 비율, 셋의 합 100, 상한 없음(`data.js` `pct`·`gauges`).
- 거리 구: `sphere.js`(그리기) · `sphere-lookup.js`(답 읽기 규칙) · `sphere-table.js`(거리표, `make_sphere_table.py`로 만듦). 어휘에 없는 답은 원 바깥 가장자리에 찍히고 거리 셈에서 빠집니다.
- 순위 알림은 수집 중 1분마다 1·2·3위에게만 「현재 N위」.

## 설정 엑셀

단어 30개·캐릭터·조건·숫자·화면 문구의 원본은 `../디알렉티카_설정_*.xlsx`(이름이 가장 뒤인 것)입니다. 고치고 저장한 뒤
`python3 ../build_settings.py`(openpyxl 필요)를 돌리면 `settings.js`가 다시 만들어집니다(`--watch`를 붙이면 저장할 때마다 자동).
화면은 `settings.js` → `data.js` 순으로 읽고, 문구는 `DLK.T("열쇠")` 또는 `data-t="열쇠"`로 꺼냅니다. ⛔ `settings.js`는 직접 고치지 않습니다.
코드에 그대로 둔 것: 게임 이름(디알렉티카 / DIALECTICA)·탭 제목·계기판(판 번호·접속 방식)·CSS·연습용 흉내 인원의 이름 재료와 흉내 답.

## 천지인 · 안드로이드

- 글자 치는 곳은 전부 화면에 보이는 진짜 입력 칸입니다 — 커서 옮기기·가운데 고치기·붙여넣기가 됩니다.
- 치는 동안에는 칸을 다시 쓰지 않습니다(천지인 조합이 끊깁니다). 정리는 버튼을 누른 뒤 한 번만.
- 버튼을 누르면 먼저 자판을 내려 조합을 끝낸 뒤 값을 읽습니다 — 마지막 글자가 빠지지 않게.
- 천지인이 남기는 점(ㆍ)과 덜 조합된 자모는 대조하기 전에 지웁니다.
- 폰에서는 화면을 꽉 채우고, 자판이 올라오면 내용만 밀어 올립니다.

## 장부를 어디에 두나 — 스스로 고릅니다

| | 언제 | 무엇 |
|---|---|---|
| **인터넷 중계** | 그냥 링크로 열었을 때 | 와이파이를 같이 쓰지 않아도 되고 LTE여도 됩니다 |
| **노트북** | `server.py`가 켜져 있을 때 | 인터넷 없이 돕니다. 폰이 노트북과 같은 와이파이여야 합니다 |
| **혼자** | 둘 다 닿지 않을 때 | 브라우저 한 대 안에서만 |

```
python3 server.py
```

주소 끝에 `?room=`을 붙이면 그 이름끼리만 같은 판이 됩니다. 예: `host.html?room=test2`
