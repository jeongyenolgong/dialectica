## 흐름

```
초대장 QR → 이름 → 고르기: 여섯 단어 중 하나 × 다섯 판 (2026.10.13) → 내 상태(고른 5개의 캐릭터 수 × 20 = 출발 비율)
→ 수집: 포스터의 단어 입력 → 그 단어의 Opposite 답(조건은 하나) → 거리 구에서 내 답의 자리 확인 + 캐릭터 게이지 +20 → 확인 → 다음 단어 (2026.10.12)
→ 리뷰 타임(스크린, 폰은 대기): 입장 때 많이 고른 단어 5개를 하나씩 — 그 단어의 구에 모인 답 전부를 점으로, 가장 먼 답을 적은 두 사람을 이름·단어로 소개 (2026.10.13)
→ 결과(스크린, 폰은 대기): 방 평균 게이지 셋 → 종료
⛔ 창작(문장 쓰기)·투표 단계는 없앴습니다(2026.10.13). `p6-create.html` · `p8p9-vote-result.html` · `screen-03-create.html` · `screen-04-vote.html`은 흐름에서 빠져 어디서도 열리지 않습니다.
```

- **팀이 없습니다.** 전부 개인전입니다.
- **포스터 코드 · 힌트가 없습니다.** 단어를 치면 폰이 30개와 견줘 찾습니다
  (띄어쓰기 무시 · 자모 하나 차이는 통과 · 30개끼리는 자모가 최소 3개씩 달라 서로 안 겹침).
- 출발 비율은 입장 때 고른 5개에서 나옵니다 — 캐릭터마다 고른 수 × 20 (한 캐릭터만 다섯이면 100·0·0). 난수 비율은 폐기.
- 고르기 다섯 판은 캐릭터마다 둘씩(30개가 10·10·10이라 남김없이), 폰마다 섞이되 같은 폰은 다시 열어도 같은 판.
- 리뷰 타임의 「가장 먼 둘」은 거리표로 잽니다. 어휘 5만에 없는 말(오타·장난)은 잴 수 없어 후보에서 빼고, 점만 껍질 바깥에 찍습니다.
- 게이지는 100에서 멈춥니다. 다 찬 캐릭터의 단어를 모아도 수집 개수(순위)는 오릅니다.
- 순위 알림은 수집 중 1분마다 1·2·3위에게만 「현재 N위」.

## 숫자와 대응은 `data.js` 한 곳에만

단어 30개 · 조건 · 캐릭터 · 셈법(+20 · +10 · 100)이 전부 `data.js`에 있습니다.
캐릭터 13개는 놀공 임시값입니다(`디알렉티카_포스터단어_출처_261007_2.xlsx`의 노란 칸 · 중간 공유회 리뷰 대상).
바뀌면 `data.js`의 그 줄만 고칩니다.

## 천지인 · 안드로이드

- 글자 치는 곳은 전부 화면에 보이는 진짜 입력 칸입니다 — 커서 옮기기·가운데 고치기·붙여넣기가 됩니다.
- 치는 동안에는 칸을 절대 다시 쓰지 않습니다(천지인 조합이 끊깁니다). 정리는 버튼을 누른 뒤 한 번만.
- 버튼을 누르면 먼저 자판을 내려 조합을 끝낸 뒤 값을 읽습니다 — 마지막 글자가 빠지지 않게.
- 천지인이 남기는 점(ㆍ)과 덜 조합된 자모는 대조하기 전에 지웁니다.
- 폰에서는 화면을 꽉 채우고, 자판이 올라오면 내용만 밀어 올립니다(화면 전체가 줄어들지 않습니다).

## 장부를 어디에 두나 — 스스로 고릅니다

| | 언제 | 무엇 |
|---|---|---|

```
python3 server.py
```
