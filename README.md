# 디알렉티카

기아 OU 워크숍 게임의 화면입니다. 2026.10.07에 초기 기획(포스터 한 장에 단어 하나)으로 돌아간 판입니다.

| 누가 | 파일 | 어디서 |
|---|---|---|
| 참가자 | `p1-identity.html` | 폰 — **초대장 QR** |
| 참가자(재접속) | `reconnect.html` | 폰 — **재접속 QR**(초대장 QR과 따로) |
| 진행자 | `host.html` | 노트북 한 대 |
| 스크린 | 진행자 화면 오른쪽 위 「스크린」 | 프로젝터 |

## 흐름

```
초대장 QR → 이름 → 내 상태(세 캐릭터 출발 비율)
→ 수집: 포스터의 단어 입력 → 그 단어의 Opposite 답(조건은 하나, 2026.10.12 반영) → 캐릭터 게이지 +20
→ 창작: 모은 단어 두 개로 문장 하나 → OU 게이지 +10 (같은 쌍은 한 번만)
→ 투표: 두 문장 중 더 좋은 것 → 결과: 표를 가장 많이 받은 문장 5개를 함께 리뷰
```

- **팀이 없습니다.** 전부 개인전입니다.
- **포스터 코드 · 힌트가 없습니다.** 단어를 치면 폰이 30개와 견줘 찾습니다
  (띄어쓰기 무시 · 자모 하나 차이는 통과 · 30개끼리는 자모가 최소 3개씩 달라 서로 안 겹침).
- 출발 비율은 첫 스캔 때 정해집니다 — 셋의 합 100 · 10 단위 · 각각 10~70.
- 게이지는 100에서 멈춥니다. 다 찬 캐릭터의 단어를 모아도 수집 개수(순위)는 오릅니다.
- 순위 알림은 수집·창작 중 1분마다 1·2·3위에게만 「현재 N위」.

## 숫자와 대응은 `data.js` 한 곳에만

단어 30개 · 조건 · 캐릭터 · 셈법(+20 · +10 · 100)이 전부 `data.js`에 있습니다.
캐릭터 13개는 놀공 임시값입니다(`디알렉티카_포스터단어_출처_261007_2.xlsx`의 노란 칸 · 중간 공유회 리뷰 대상).
바뀌면 `data.js`의 그 줄만 고칩니다.

## 천지인 · 안드로이드

- 글자 치는 곳은 전부 화면에 보이는 진짜 입력 칸입니다 — 커서 옮기기·가운데 고치기·붙여넣기가 됩니다.
- 치는 동안에는 칸을 절대 다시 쓰지 않습니다(천지인 조합이 끊깁니다). 정리는 버튼을 누른 뒤 한 번만.
- 버튼을 누르면 먼저 자판을 내려 조합을 끝낸 뒤 값을 읽습니다 — 마지막 글자가 빠지지 않게.
- 천지인이 남기는 점(ㆍ)과 덜 조합된 자모는 대조하기 전에 지웁니다.
- 폰에서는 화면을 꽉 채우고, 자판이 올라오면 내용만 밀어 올립니다(화면 전체가 줄어들지 않습니다).

## 장부를 어디에 두나 — 스스로 고릅니다

| | 언제 | 무엇 |
|---|---|---|
| **인터넷 중계** | 그냥 링크로 열었을 때 | 와이파이를 같이 쓰지 않아도 되고 LTE여도 됩니다 |
| **노트북** | `server.py`가 켜져 있을 때 | 인터넷 없이 돕니다. 폰이 노트북과 같은 와이파이여야 합니다 |
| **혼자** | 둘 다 닿지 않을 때 | 브라우저 한 대 안에서만 |

```
python3 server.py
```

주소 끝에 `?room=` 을 붙이면 그 이름끼리만 같은 판이 됩니다. 예: `host.html?room=test2`
